# سینا نور — پروژه فرانت‌اند فروشگاه

این پروژه پیاده‌سازی HTML/CSS/JS از کیت طراحی «سینا نور» است: صفحه اصلی (شامل هدر، اسکرول دسته‌بندی، بنر اسلایدر، بخش پیشنهاد شگفت‌انگیز، ناوبری پایین موبایل و دکمه شناور واتساپ) و صفحه ورود/ثبت‌نام با فلوی OTP دو مرحله‌ای، هم برای موبایل و هم دسکتاپ (ریسپانسیو).

## ساختار فایل‌ها
```
index.html      صفحه اصلی فروشگاه
login.html      صفحه ورود / ثبت‌نام (OTP)
css/style.css   کل دیزاین سیستم (رنگ، تایپوگرافی، کامپوننت‌ها) + رسپانسیو دسکتاپ
js/main.js      منطق منوی کشویی، اسلایدر، رندر کارت محصولات صفحه اصلی
```

## اجرا
هیچ نصب یا بیلدی لازم نیست. کافی است فایل `index.html` را در مرورگر باز کنید،
یا برای تجربه بهتر (به‌خصوص روی موبایل با فونت آنلاین) یک سرور محلی ساده اجرا کنید:

```bash
cd sina-noor
python3 -m http.server 8080
# سپس در مرورگر: http://localhost:8080
```

## نکات مهم برای توسعه بعدی
- تصاویر محصولات و بنرها فعلاً به‌صورت **پلیس‌هولدر گرادیانی** (کلاس‌های `.ph-1` تا `.ph-5`) پیاده شده‌اند؛ کافی‌ست در `js/main.js` آرایه `products` و بنرهای `index.html` را با تصاویر واقعی (از R2 یا CDN) جایگزین کنید.
- فونت وزیرمتن از Google Fonts لود می‌شود؛ برای عملکرد آفلاین/PWA بهتر است فایل فونت را لوکال کرده و در `css/style.css` مسیر `@import` را به فایل محلی تغییر دهید.
- این نسخه فقط فرانت‌اند استاتیک است (بدون بک‌اند). طبق کیت طراحی، مرحله بعد اتصال به API روی Cloudflare Workers/D1 برای احراز هویت OTP واقعی، محصولات، سبد خرید و پنل مدیریت مجزاست.
- پنل مدیریت (admin) و پنل کاربری کامل در این تحویل نیستند و باید به‌صورت مجزا (ترجیحاً ساب‌دامنه admin.sinanoor.com) ساخته شوند، همان‌طور که در سند کیت طراحی آمده.
