# سینا نور — پروژه کامل (فرانت فروشگاه + بک‌اند + پنل مدیریت)

این پکیج نسخه‌ی تکمیل‌شده‌ی پروژه‌ی اولیه است. تصمیم‌های اعمال‌شده طبق پاسخ‌های شما:

- **بک‌اند:** Cloudflare Workers + D1 (طبق پیشنهاد README اصلی)
- **پنل مدیریت:** روی ساب‌دامنه‌ی مجزا (`admin.sinanoor.com`)، مدیریت کامل محصولات / سفارش‌ها / کاربران / دسته‌بندی‌ها
- **احراز هویت:** رمز عبور ساده (شماره موبایل + پسورد) به‌جای فلوی OTP دو مرحله‌ای

## ساختار پوشه‌ها
```
backend/    Cloudflare Worker + D1  (API واقعی — جایگزین داده‌های ثابت)
frontend/   همان فروشگاه اصلی (index.html) + login.html بازنویسی‌شده با رمز عبور + account.html
admin/      پنل مدیریت مجزا، برای دیپلوی روی ساب‌دامنه admin
```

## گام‌های راه‌اندازی

### ۱) بک‌اند
به `backend/README.md` مراجعه کنید: ساخت D1، اجرای `schema.sql`، تنظیم `JWT_SECRET`، `wrangler deploy`.
بعد از دیپلوی، آدرس Worker را (مثلاً `https://api.sinanoor.com` یا آدرس `*.workers.dev`) در دو جای زیر ست کنید:

```html
<!-- بالای فایل‌های frontend/index.html، frontend/login.html، frontend/account.html
     و admin/login.html، admin/index.html — قبل از <script src="js/api.js"> اضافه کنید -->
<script>window.SINA_NOOR_API_BASE = "https://api.sinanoor.com";</script>
```
(در حال حاضر این مقدار به‌صورت پیش‌فرض روی `https://api.sinanoor.com` تنظیم شده — کافی‌ست دامنه‌ی واقعی خودتان را جای‌گزین کنید.)

### ۲) فرانت‌اند فروشگاه
همان `frontend/` قبلی است؛ فقط:
- `login.html` حالا فلوی رمز عبور دارد (ورود/ثبت‌نام واقعی، متصل به API).
- `js/main.js` محصولات را از API می‌خواند و در صورت نبود بک‌اند به داده‌ی نمونه برمی‌گردد (fallback) تا سایت هرگز خراب نشود.
- `account.html` صفحه‌ی ساده‌ی «حساب من» با نمایش سفارش‌ها و دکمه خروج اضافه شده.
- `cart.html` صفحه‌ی سبد خرید و تسویه حساب: افزایش/کاهش تعداد، حذف کالا، فرم آدرس و ثبت نهایی سفارش (متصل به `POST /api/orders`).
- دکمه‌ی «افزودن به سبد» روی هر کارت محصول در صفحه اصلی اضافه شده و شمارنده‌ی سبد در هدر و ناوبری پایین به‌صورت زنده به‌روزرسانی می‌شود (`js/cart.js`، مبتنی بر localStorage).
- اگر کاربر لاگین نباشد، هنگام ثبت نهایی سفارش به `login.html` هدایت می‌شود؛ سبد خرید بعد از ورود در همان مرورگر باقی می‌ماند.
- روی دامنه‌ی اصلی (`sinanoor.com`) دیپلوی می‌شود — هر هاست استاتیک (Cloudflare Pages، Netlify، …) کافی است.

### ۳) پنل مدیریت
پوشه‌ی `admin/` را روی ساب‌دامنه‌ی جدا (مثلاً `admin.sinanoor.com`) دیپلوی کنید — کاملاً مستقل از فرانت اصلی، فقط با همان بک‌اند صحبت می‌کند.
- اولین کاربری که در فرانت اصلی (`login.html` → ثبت‌نام) ساخته می‌شود، خودکار نقش `admin` می‌گیرد (نکته امنیتی در `backend/README.md`).
- با همان شماره موبایل و رمز عبور در `admin/login.html` وارد شوید.
- بخش‌های محصولات، دسته‌بندی‌ها، سفارش‌ها (با تغییر وضعیت) و کاربران (ارتقا/تنزل نقش، حذف) به‌صورت کامل پیاده شده‌اند.

## چک‌لیست قبل از پروداکشن
- [ ] `database_id` واقعی D1 را در `backend/wrangler.toml` جای‌گزین کنید
- [ ] `JWT_SECRET` را با `wrangler secret put` ست کنید (رشته‌ی تصادفی قوی)
- [ ] `ALLOWED_ORIGINS` در `wrangler.toml` را با دامنه‌های واقعی خودتان به‌روزرسانی کنید
- [ ] `SINA_NOOR_API_BASE` را در فایل‌های frontend/admin با آدرس واقعی Worker جایگزین کنید
- [ ] رفتار «اولین ثبت‌نام = ادمین» را بعد از ساخت اولین ادمین غیرفعال کنید
- [ ] HTTPS و ساب‌دامنه‌ها را در Cloudflare DNS/Routes متصل کنید
